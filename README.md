# Doron Tools עם דשבורד חשיפות חיסכון

מה עודכן:

1. נוסף כלי חדש למסך Doron Tools: "דשבורד חשיפות חיסכון".
2. הכלי נוסף גם לתפריט הצד וגם לכרטיסי הכניסה במסך הבית.
3. לפני כניסה לכלי מתוך Doron Tools מופיע מסך גילוי נאות, ורק לאחר אישור המשתמש הכלי נפתח.
4. נוסף מסך גילוי נאות גם בתוך הדשבורד עצמו, כדי לחסום כניסה גם אם המשתמש מגיע ישירות לכתובת הכלי.
5. קובץ הנתונים `funds_unified.json` נשמר ליד קובץ הדשבורד, כי הדשבורד טוען אותו באמצעות `fetch('./funds_unified.json')`.

מבנה התיקייה:

```
index.html
README.md
dashbord-pensioni1/
  index.html
  funds_unified.json
```

העלאה ל-GitHub Pages:

- העלה את כל התיקייה כפי שהיא לריפו של Doron Tools.
- אם הכלי אמור לשבת בריפו נפרד, פתח את `index.html` הראשי, חפש `savings-dashboard`, והחלף את `url: './dashbord-pensioni1/'` לכתובת המלאה של GitHub Pages, לדוגמה:
  `https://doronsh170.github.io/dashbord-pensioni1/`

הערה:

האישור לגילוי הנאות נשמר באמצעות `sessionStorage`, כלומר הוא תקף לטאב או לסשן הנוכחי בלבד. בסשן חדש המשתמש יתבקש לאשר שוב.
