# Doron Tools

מעטפת (hub) לכלים לניתוח שוק ההון ולתכנון פיננסי ופנסיוני.

האתר הוא קובץ סטטי יחיד — `index.html` — ללא תלויות, ללא שלב build וללא framework.
הוא נטען מיידית ומתארח כמו שהוא ב‑GitHub Pages.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האתר: מבנה, עיצוב, אייקונים ולוגיקה |
| `README.md` | המסמך הזה |

## הוספה או עדכון של כלי

כל הכלים מוגדרים במקום אחד בלבד — מערך `TOOLS` שבתוך ה‑`<script>`.
הסרגל הצדדי, כרטיסי המסך הראשי, כותרת הכלי וגילוי הנאות נבנים ממנו אוטומטית,
כך שאין צורך לעדכן את השם ביותר ממקום אחד.

```js
{
  id:   'tool-id',              // מזהה ייחודי
  name: 'שם הכלי',              // מוצג בסרגל, בכרטיס ובכותרת הכלי
  meta: 'תיאור קצר',            // שורת המשנה בסרגל הצדדי
  desc: 'תיאור לכרטיס',         // שתי שורות במסך הראשי
  cat:  'market',               // 'market' או 'planning'
  icon: 'i-momentum',           // id של <symbol> בספריית האייקונים
  url:  'https://...',
  disclaimer: { subtitle: '...', html: '<p>...</p>' }
}
```

- **קטגוריות** מוגדרות במערך `CATEGORIES`. כחול = שוק ההון ומסחר, ירוק = תכנון פיננסי.
- **אייקונים** הם `<symbol>` בתוך ספריית ה‑SVG בראש ה‑`<body>`. להוספת אייקון חדש
  יש להוסיף `<symbol>` עם `id` ולציין את ה‑`id` בשדה `icon`.
- **גילוי נאות** הוא חובה לכל כלי. כלי ללא `disclaimer` ייפתח ללא מסך אישור.
- **גרסה ותאריך עדכון** נמצאים באובייקט `SITE` בראש הסקריפט.

## התנהגות

- **דסקטופ (‏1024px ומעלה):** סרגל צדדי קבוע; הכלי נטען ב‑iframe בתוך המעטפת.
- **מובייל וטאבלט (מתחת ל‑1024px):** סרגל נפתח כמגירה; הכלי נפתח בלשונית חדשה
  כדי שהמעטפת תישאר פתוחה. אם הדפדפן חוסם חלונות קופצים, המערכת עוברת לניווט רגיל.
- **גילוי נאות** מוצג לפני הכניסה לכל כלי, ונשמר ל‑session אחד בלבד (`sessionStorage`).
- **מקש Escape** סוגר את חלון גילוי הנאות או את המגירה. הוא **אינו** יוצא מכלי פתוח,
  כדי שלא תאבד עבודה שבוצעה בתוך הכלי.

## נגישות

- ניווט מלא במקלדת; כל הכלים הם `<button>` ולא `<div>`.
- מצבי `:focus-visible` גלויים בכל רכיב אינטראקטיבי.
- כל טקסט עומד ביחס ניגודיות WCAG AA (‏4.5:1 ומעלה).
- חלון גילוי הנאות הוא `role="dialog"` עם `aria-modal`, מלכודת פוקוס והחזרת פוקוס.
- `dir="rtl"` עם מאפייני CSS לוגיים (`inset-inline`, `margin-inline`).
